Want to play on an offline server with friends but don't want to use authentication mods?

This mod fixes the issue where offline players can't be added to the whitelist.

**Find the Project Page on [Modrinth](https://modrinth.com/mod/bta-whitelist)**

___

### How to use it?
Everything is easy, just use the `/whitelist` command as intended, it'll automatically add or remove nicknames to the custom whitelist file.

___

### Installation
   
1. Download mod version which supports your BTA! version.
2. Make sure your server using Babric, so it can support mods.
3. Put mod into your server's `/mods` folder.
4. Restart your server!

___

_This mod uses a modified version of Fabric (Babric) and is designed only for Better than Adventure, a heavily modified version of Minecraft b1.7.3! For more information, join the discord server provided on this projects page._
